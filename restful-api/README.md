# Python - RESTful API

## Description

This project introduces the fundamentals of RESTful APIs using Python. It covers the basics of HTTP/HTTPS, consuming APIs using command-line tools and Python, building APIs with Python's built-in modules and Flask, and implementing API security and authentication techniques.

The project provides hands-on experience with requesting, processing, creating, and securing RESTful web services.

---

## Learning Objectives

By the end of this project, I learned how to:

- Understand the fundamentals of HTTP and HTTPS.
- Differentiate between HTTP and HTTPS.
- Understand HTTP requests and responses.
- Recognize common HTTP methods and status codes.
- Use `curl` to interact with REST APIs.
- Consume REST APIs using Python.
- Parse JSON responses.
- Process and export data into CSV files.
- Build a simple API using Python's `http.server` module.
- Build REST APIs using Flask.
- Implement API security and authentication.
- Understand REST API best practices.
