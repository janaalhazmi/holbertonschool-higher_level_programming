# JavaScript - DOM Manipulation

This project contains JavaScript exercises focused on manipulating HTML elements using the DOM.

## Tasks

### 0. Color Me
Write a JavaScript script that updates the text color of the `header` element to red (`#FF0000`).

The script must use `document.querySelector` to select the HTML tag.

### 1. Click and turn red
Write a JavaScript script that changes the text color of the `header` element to red when the user clicks on it.

### 2. Add `.red` class
Write a JavaScript script that adds the `red` class to the `header` element when it is clicked.

### 3. Toggle classes
Write a JavaScript script that toggles the `red` class on the `header` element when it is clicked.

### 4. List of elements
Write a JavaScript script that selects multiple elements and manipulates them using the DOM.

### 5. Change the text
Write a JavaScript script that changes the text of an HTML element when the user interacts with the page.

### 6. Star Wars character
Write a JavaScript script that retrieves a Star Wars character from an API and displays the character's name in the page.

### 7. Star Wars movies
Write a JavaScript script that retrieves Star Wars movies from an API and displays their titles in a list.

### 8. Say Hello
Write a JavaScript script that retrieves a translation and displays a greeting on the page.

## Concepts

These exercises cover:

- DOM manipulation
- `document.querySelector`
- `document.querySelectorAll`
- `addEventListener`
- `classList`
- `classList.add()`
- `classList.toggle()`
- `textContent`
- `value`
- `createElement`
- `appendChild`
- JavaScript loops
- `fetch`
- APIs
- JSON
- Promises

## Requirements

- Use JavaScript to manipulate HTML elements.
- Follow the requirements of each task.
- Do not use `var`.
- Use `const` and `let` where appropriate.
- Follow the project's JavaScript coding style.
- Test the scripts in a web browser.
