# SQL Introduction

This project introduces the fundamentals of SQL using MySQL.

## Learning Objectives

- Understand what SQL is and why it is used.
- Create and manage databases.
- Create, modify, and delete tables.
- Insert, update, and delete data.
- Retrieve data using SQL queries.
- Filter, sort, and organize query results.
- Use MySQL from the command line.

## Requirements

- Ubuntu 24.04 LTS
- MySQL 8.0
- All SQL scripts are tested using MySQL.

## Files

Each `.sql` file contains the solution for a specific task in the project.
